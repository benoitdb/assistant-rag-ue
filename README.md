# Assistant RAG réglementaire — fonds européens de cohésion

Assistant documentaire qui répond en langage naturel sur la réglementation
des fonds européens de cohésion (FEDER, FSE+), pour l'aide à l'instruction
et à l'audit. Portfolio / démo, pas un outil de production — voir
l'avertissement affiché dans l'application.

Corpus V1 : Règlement (UE) 2021/1060, Décret n° 2022-608, Guide du porteur
de projet Centre-Val de Loire. Détails du projet et des choix techniques
dans [`CLAUDE.md`](CLAUDE.md) et [`docs/decisions/`](docs/decisions/) sur
le [dépôt GitHub](https://github.com/benoitdb/assistant-rag-ue).
